## 💻 Cara Menjalankan di Komputer Lokal

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Jalankan Server Development:**
   ```bash
   npm run dev
   ```
   Buka browser di `http://localhost:5173`

3. **Build untuk Produksi:**
   ```bash
   npm run build
   ```
   Folder hasil build ada di `dist/`.
